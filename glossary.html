Glossary

The words, in plain English

106 terms from audio, MIDI, plugins, mixing and AI music that turn up in the app and this manual.

Audio files and deliverables

Stem
One track, or one group of tracks (all drums, all synths), rendered to its own audio file, full length, starting at bar 1, so that playing every stem together reproduces the mix.
Mix, mixdown
All tracks summed to one stereo file with levels, pans and effects applied.
Master, mastering
The final pass on a finished mix: overall EQ, compression, a limiter, and loudness set to a target so it sits at the same level as commercial releases.
Bounce, render
Writing audio to a file instead of playing it live. "Bounce in place" renders one track to audio inside the project.
Dry, wet
Dry is a signal before effects; wet is after. A "dry stem" has no reverb or compression on it.
Pre-fader, post-fader
Whether a signal is tapped before or after the track's volume fader. Post-fader stems reflect your mix levels; pre-fader stems are at raw level.
Sample rate
How many audio samples per second. 44.1 kHz is CD; 48 kHz is the DAW, film and game standard.
Bit depth
Bits per sample. 16-bit is CD; 24-bit is the production standard; 32-bit float cannot clip.
Clipping
Signal exceeding the maximum level, producing distortion.
LUFS
Loudness Units relative to Full Scale: the loudness measure streaming services use. Spotify normalises to about -14 LUFS; game audio middleware often targets -16 to -18.
True peak, dBTP
The highest level the waveform reaches between samples. Streaming services ask for -1 dBTP.
Headroom
Space left between the loudest peak and 0 dBFS.
Loop points
Sample positions where playback jumps back so a track repeats seamlessly, usually bar-aligned.
One-shot, hit
A single short sample (a kick, a snare) triggered by one note.
Sample
A recorded audio snippet used as an instrument or a sound. Also the individual numeric value in digital audio.
Loop
A short audio phrase (1 to 8 bars) made to repeat.
Normalise
Scale a file so its peak (or its loudness) hits a target.
Multitrack
A session or export with every track kept separate.

MIDI and notes

MIDI
A protocol and file format for note events (which note, when, how hard, how long) and controls, with no audio in it. The instrument that plays it decides the sound.
Type 0, Type 1 MIDI file
Type 0 puts every part on one track; Type 1 keeps one track per part. DAWs import Type 1 as separate tracks.
Note on, note off
The event that starts a note and the one that ends it. Length is the gap between them.
Velocity
How hard a note was struck, 1 to 127. Drives volume and often timbre. Flat velocity is the main reason generated MIDI sounds mechanical.
Ticks, PPQ
MIDI time is counted in ticks per quarter note (PPQ or PPQN), commonly 480 or 960. Swing and micro-timing are offsets in ticks.
Tempo, BPM
Beats per minute. A MIDI file carries tempo as a meta event, and can change it mid-song.
Time signature, meter
Beats per bar and the beat unit: 4/4, 3/4, 6/8. Also a MIDI meta event.
Meta event
Non-note data in a MIDI file: tempo, time signature, key, track name, markers, lyrics.
Marker
A named position on the timeline (Intro, Verse, Chorus).
CC, control change
Continuous controller messages: mod wheel (CC1), volume (CC7), pan (CC10), sustain pedal (CC64), expression (CC11).
General MIDI, GM
A 1991 standard assigning fixed instrument numbers (1 = piano, 33 = acoustic bass, 128 = gunshot) and a fixed drum map, so any GM device plays a file roughly right. Also the cliché sound of cheap 1990s synths.
GM drum map
The GM convention for which note number is which drum on channel 10: 36 kick, 38 snare, 42 closed hat, 46 open hat, 49 crash, 51 ride.
Channel
One of 16 MIDI streams in a file; channel 10 is drums by GM convention.
Quantize
Snap note starts (and sometimes lengths) to the grid. Over-quantized music sounds robotic.
Grid, subdivision
The rhythmic resolution notes snap to: 1/8, 1/16, triplets.
Swing, shuffle
Delaying every second subdivision so pairs of notes go long-short. Light swing is 55 to 58 percent; heavy is 62 to 67.
Humanisation
Small random or rule-based variations in velocity, timing and length so a part sounds played rather than programmed.
Micro-timing
Deliberate pushes and pulls of a few milliseconds off the grid, per instrument (a laid-back snare, a pushed hi-hat).
Articulation
How a note is played: staccato, legato, slide, ghost note, accent. Sample libraries switch articulations with key switches.
Ghost note
A very quiet note, usually on snare or bass, that adds feel without being heard as a hit.
Piano roll
The note editor: time across, pitch down, notes as bars.
Step sequencer, drum grid
A grid of steps per drum where each cell is on or off, with velocity.
Clip
A block of notes (or audio) with a start and length, placed on a track.
Arrangement
The order and length of sections across the song.
Chord track, chord lane
A lane showing the chord per bar; in Logic and Cubase other parts follow it when you change a chord.
Key, scale
The home note and the set of notes a song uses (C minor). Scale lock restricts notes to the scale.
Voicing, inversion
Which notes of a chord go where (close, open, spread) and which note is lowest.
Motif, riff, hook
A short repeated melodic idea; a riff is usually rhythmic and on guitar or bass; a hook is the memorable one.
Arpeggio, arp
A chord played one note at a time; an arpeggiator does it automatically.

Plugins and instruments

Plugin
A synth or effect loaded inside a host program. An instrument plugin takes MIDI in and gives audio out; an effect plugin takes audio in and out.
VST
Steinberg's plugin standard and trademark. VST2 (1999) is closed and can no longer be licensed; VST3 (2008) is the current one, MIT-licensed since Oct 2025. "VSTi" is an old term for a VST instrument that Steinberg asks you not to use.
Host
The program that loads plugins and feeds them MIDI and audio: a DAW, or a library like pedalboard.
Headless
Running without a window or UI.
Offline rendering
Rendering faster than real time to a file, instead of playing live. Plugins must support it; most do.
Real-time
Processing audio as it plays, with latency small enough to perform with.
Preset, patch
A saved set of a synth's parameter values. Patch is the older word. A bank is a set of presets.
Plugin state
The full parameter blob a host saves and restores for a plugin.
Parameter
One controllable value in a plugin (cutoff, attack). VST3 exposes them by ID for automation.
Mono, poly
Monophonic plays one note at a time (basses, leads); polyphonic plays chords.
Sampler
An instrument that plays recorded audio files pitched across the keyboard.
SFZ
An open text format describing a sample instrument: which WAV plays for which key and velocity, with envelopes and loops. Engine: sfizz (archived Jun 2026).
SF2, SoundFont
An older binary sample-instrument format; SF3 is the compressed version, played by engines such as FluidSynth.
Velocity layer
Different samples for soft, medium and hard hits so loud notes sound different, not just louder.
Round robin
Alternating among several recordings of the same note so repeats don't sound identical.
Wavetable synth
A synth that scans through stored single-cycle waveforms (Vital, Surge).
FM synth
Frequency-modulation synthesis, the DX7 sound. Dexed is a DX7 clone.
Subtractive, analogue-style
Oscillators into filters, the Moog and Oberheim model.
303
The Roland TB-303 acid bassline sound.
Chiptune, 8-bit
Music from early console sound chips: square waves, noise channels.
MIDI effect
A plugin that transforms notes rather than audio: arpeggiator, chord, scale, humanizer.
pedalboard
Spotify's Python library for hosting VST3 plugins and rendering audio. GPLv3.

Mixing and effects

Mixer
The per-track controls: gain (volume), pan (left-right), mute, solo, effects, and routing.
Fader
The volume control on a mixer channel.
Bus, group
A channel that several tracks are summed into (a drum bus) so they can be processed together. The master bus is the final one.
Send, return, aux
Routing a copy of a track to a shared effect (one reverb for everything) instead of one effect per track.
Insert
An effect placed directly in a track's signal path.
Compressor
Reduces the level of loud parts so the quiet parts can come up; controls dynamics. Threshold, ratio, attack, release.
Sidechain compression
A compressor on one track (bass) triggered by another (kick), so the bass ducks whenever the kick hits. The standard fix for kick/bass masking.
Gate
Mutes a signal below a threshold; removes noise and tails.
Limiter
A compressor with an infinite ratio that stops peaks passing a ceiling; the last device on a master.
EQ, equaliser
Adjusts level per frequency band. A parametric EQ has freely set bands; a highpass filter cuts lows below a point.
Reverb
Simulated room reflections.
Delay
Echoes.
Chorus
Doubling with slight pitch and time variation for width.
Saturation
Mild harmonic distortion that adds warmth and density.
Masking
One sound hiding another in the same frequency range, most often kick and bass under 150 Hz.
Frequency balance, spectrum
How energy is spread across lows, mids and highs.
Stereo field, width
How sounds are spread left to right. Bass is usually centred (mono).
Transient
The sharp attack at the start of a hit.
Automation
Recording a parameter's changes over time (a filter opening across 8 bars, volume dipping for a drop) as a lane on the track.
Dynamics, dynamic range
The gap between the loudest and quietest parts.

DAW and workflow

DAW
Digital Audio Workstation: the program producers live in (Ableton Live, FL Studio, Logic, Cubase, Reaper, Bitwig, Studio One, Ardour). Records, edits, mixes, hosts plugins.
Arrangement view, timeline
The left-to-right song layout of tracks and clips.
Track
One instrument's or one audio source's lane.
Take
One recorded pass. Comping is picking the best bits from several takes.
Project, session
The saved file for a song and everything in it.
Backing track
A full band recording minus one part, for practising or performing over.
CLI, API
Command-line interface; programmable interface. The Jukebox has both: see Scripting.
MCP, Model Context Protocol
A standard for exposing tools to AI agents so Claude Code, Codex or opencode can call them. AbletonMCP, reaper-mcp and Resonant expose their apps this way.

AI terms

Plan-then-render
An LLM writes structure (tempo, key, sections, chords, sounds); code or a model realises it. YuE2 and ACE-Step 1.5 added a planning stage in 2026.
Deterministic
Same inputs give the same output every time.
Seed
The number that fixes a random generator's sequence; same seed, same result.
Critic
An automatic check on the result (key consistency, level balance, masking, section energy, timing) that triggers a revision.
Revision loop
Generate, check, fix, repeat up to N rounds.
Persona
A preset that steers genre and arrangement choices (Producer, Club DJ, Jazz cat).
Local model
An LLM or audio model running on your own machine (Ollama, LM Studio, llama.cpp).
OpenAI-compatible endpoint
An HTTP API that mimics OpenAI's chat format, so one client talks to Ollama, LM Studio, OpenRouter or OpenAI.
JSON mode, structured output
Forcing the LLM to answer in valid JSON that matches a schema.
