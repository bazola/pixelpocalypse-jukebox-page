Setup

Get it running

Six steps, about half an hour, most of it downloads. Windows only for now: the plugin builds and paths are Windows ones.

1 · Install the tools (once)

  • uv, for Python and its packages. In PowerShell: 
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  • Node.js LTS, to build the editor.
  • Git.

2 · Get the code

git clone https://github.com/bazola/super-music-sound.git
cd super-music-sound

3 · Get the plugins

Most are free and download from their own releases, checksummed: about 3.7 GB, mostly the VSCO2 orchestra and the bass guitars.

uv run python scripts/fetch_plugins.py
  • It also downloads and runs the installers for OB-Xd and Odin 2 (both free; Windows asks for admin once each). --no-installers skips them.
  • Each download shows its license as it lands. Libraries whose license doesn't allow sharing them are only ever downloaded at install, never kept in the repository.
  • The four mda instruments (JX10, DX10, ePiano, Piano) are built from source, and only when Visual Studio 2022 or later (the free Community edition, with "Desktop development with C++") is installed. They're optional: without it their sounds aren't offered.
  • One plugin you install yourself, and it's optional too: Surrealistic MG-1 Plus (Cherry Audio, paid). The favourite basses are this one; without it, its sounds simply aren't offered.

4 · A local LLM

Run Ollama or LM Studio with a model that's good at JSON: a 12B+ instruct model, and bigger plans better. Then:

copy .env.example .env

and set LLM_BASE_URL and LLM_MODEL in .env (the file explains both):

# Ollama
LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=qwen3:14b
# LM Studio
LLM_BASE_URL=http://localhost:1234/v1
LLM_MODEL=<the model id it shows>

Give the model a 16k context. The planner's prompt is long (it carries the sound catalog). Ollama keeps 2-4k unless you set the environment variable OLLAMA_CONTEXT_LENGTH=16384 before starting it; LM Studio asks when you load a model.

Any OpenAI-compatible server with structured output works, local or not. Set LLM_API_KEY only if yours wants one.

5 · Check

uv run python scripts/doctor.py

It says what's missing and how to fix it, and makes one real LLM call.

6 · Start

Double-click start.bat (or run it). The first time, it builds the editor. Then it opens http://127.0.0.1:8000. Close its window to stop the app.

Then try the first prompt: open AI, choose New song, type what you want and press Ctrl+Enter. The manual takes it from there →

Updating

git pull
uv run python scripts/fetch_plugins.py

fetch_plugins.py gets only the plugins that are new since last time. start.bat rebuilds the editor by itself when the pull changed it (start.bat build forces it). scripts/doctor.py says if anything is missing.

If something's wrong

  • Run the doctor first. It checks the tools, the plugins, .env and the LLM, and says how to fix each.
  • Generate fails at planning, or the plan is cut off: the model's context is too small (see step 4), or the model isn't good at JSON. Try a bigger one; the AI panel's model picker lists everything your server offers.
  • A sound is missing from the library: its plugin isn't installed. Run fetch_plugins.py again, or add a folder of your own VST3s with SMS_VST3_DIRS in .env.
  • An AI assistant gives up on a long generate over MCP: raise its tool timeout, or ask for a quick draft (Scripting).
